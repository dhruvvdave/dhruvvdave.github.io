Work

Markr — stock screener

Free market-data APIs cap you hard, and every provider caps you differently. Markr chains six of them — Finnhub through Yahoo Finance, FMP, Alpha Vantage, Stooq, and Twelve Data — behind a FastAPI backend that enforces per-source rate limits with an atomic Redis Lua script, so a burst of traffic fails over instead of failing. Candles land asynchronously in a monthly-partitioned Postgres table, and the indicators (RSI, MACD, Bollinger Bands) are computed client-side from raw history, which keeps the backend a dumb, fast cache.

React · FastAPI · PostgreSQL · Redis · Docker Demo Source

SecureVault — password manager

Built to understand what 1Password is actually doing. Every vault entry is encrypted with its own AES-256-GCM key, derived with PBKDF2 at 600,000 iterations, so cracking one entry buys you nothing else. Breach checks use HaveIBeenPwned's k-anonymity model — five characters of a hash leave the machine, never the password. Rounded out with bcrypt logins, rotating JWTs, TOTP two-factor, and a pytest suite, deployed behind nginx.

Flask · React · SQLite · Docker Demo Source

ctx — browser session tracker

A session tracker designed to work with the network unplugged. The Chrome extension batches sessions with chrome.alarms and persists them locally, so the Hono backend and CLI — same TypeScript monorepo — are optional extras. The part that took longest is the privacy guard: before anything is captured, a content script checks the URL against a sensitive-domain list and scans the live DOM for password and credit-card fields.

TypeScript · Chrome MV3 · Hono · SQLite Source

Wavvy — drum machine for the browser

A 16-step sequencer and melody pads scheduled with Tone.js, with five visualizer modes drawn in real time from the Web Audio analyser node. Made for making noise; kept because the scheduling was a genuinely hard timing problem.
