Projects

01

Algorithmic Trading Bot

Trend-following system for US equities. Paper trading only.

EMA(12/26) crossovers behind a 200-SMA filter, with ATR trailing stops. A risk manager sizes each position by the equity it puts at risk, halts on a daily-loss or drawdown limit, and persists the halt state so a restart does not clear it. A backtester runs the same strategy code the bot runs live over 5 years of daily bars and reports return, drawdown, Sharpe, and win rate.

Positions were being sized wrong across CAD and USD; async caching of FX rates from IBKR forex data fixed it. Signals are only evaluated between 3:50 and 4:00pm ET, so the bot never trades on an unfinished daily bar. IB Gateway runs headless (IBC, Xvfb) beside the bot in Docker Compose on DigitalOcean for 24/7 paper trading, and Telegram commands pause it, report P&L, and close positions. Tested with pytest.

  • Python (asyncio)
  • Interactive Brokers API
  • Docker Compose
  • DigitalOcean

02

Markr

Stock screener with a six-source data fallback chain.

Six market-data APIs behind one FastAPI backend. A Redis Lua script enforces each source's rate limit atomically, so a burst of traffic falls through the chain rather than failing on a 429. Candles write asynchronously to monthly-partitioned Postgres with per-resolution Redis TTLs; RSI, MACD, and Bollinger Bands are computed client-side. A Vitest suite covers the fallback chain, the indicators, and the limiter.

  • FastAPI
  • PostgreSQL
  • Redis

04

SecureVault

Password strength analyzer, breach check, and generator.

The analyzer charges each guessable part of a password what it costs to guess: dictionary words (leet swaps included), keyboard walks, sequences, and dates. Summer2024! has 72 naive bits but scores 22. The breach check hashes with SHA-1 in the browser and sends Have I Been Pwned only a 5-character prefix; the CSP blocks every other host. A CSPRNG generator reports exact entropy, and Playwright tests fail if any request carries the password or its full hash.

  • React
  • Vite
  • Web Crypto
  • Playwright
  • Docker
